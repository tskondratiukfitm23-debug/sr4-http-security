# Звіт —СР №4. Безпека мережевого протоколу (аналіз, виявлення загроз, впровадження покращень)

- Посилання на RFC/OWASP, короткий опис класів ризиків (перехоплення, маніпуляція, downgrade, cookie/headers).

## 2. Вектори атак (демо)

## 3. Покращення
- TLS 1.3, HSTS, CSP, Secure/HttpOnly/SameSite cookies, політика протоколів/шифрів.

## 4. Вплив на ефективність/сумісність
